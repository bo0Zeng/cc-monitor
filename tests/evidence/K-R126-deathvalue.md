## 〇 · 一句话

**CI 红的不是中转（产品代码），是那一族测试自己的假上游桩。**
桩把「下游中途走人」这一**合法**的客户端行为当成夹具坏了，用 `.expect()` 炸掉自己的 accept 线程，
连带 `listener` 一起 drop ⇒ **同一条判据里的第二发 `Connection refused`** ⇒ 502 ⇒ 红。

## 一 · 根因（`KR126D1`）

### 1.1 因果链 —— **`Broken pipe` 是根，`Connection refused` 是果**

```
STUB_LAUNCHER 的 `head -n 1 <&3`  ——（读到状态行就退出，bash 一退连接就没了）
  ⇒ 中转写下游 → Broken pipe → 中转照规矩收掉它那条上游连接
    ⇒ 假上游桩接着写第 i 块 → Broken pipe
      ⇒ 那几处全是 `.expect(...)` ⇒ **桩的 accept 线程 panic**
        ⇒ `listener` 被一起 drop
          ⇒ 同一条判据里**第二发** `Connection refused (os error 111)` ⇒ 中转回 502 ⇒ 红
```

🔴 **PM 在 `§0a` 给的方向（「桩还没 listen 上，中转就连过去」）是反的，已推翻**：
`bind` 发生在 `spawn` **之前**、`addr` 就是从 `listener` 上取的
⇒ **地址存在的那一刻它已经在听了**。它不是没起来，是**听着听着被自己炸没的**。

### 1.2 「两者之间今天有没有任何同步」

**有，而且从来不缺**：中转拿到的地址来自一个**已经 bind 过**的 `listener`。
⇒ 单子里那条「等桩真的 listen 上再放中转过去」的修法**治的不是这个病**，本件没有采用（理由即 1.1）。

### 1.3 本地复现 —— **不掷骰子，5/5 必红**

复现刀 `repro-slow-upstream`（`evidence/K-R126-cut.py`，锚点命中 1/1）：
假上游每写一块之前先睡 300ms。**它不改任何判定逻辑，只改时序** ——
把 CI 上那个「桩写到一半、下游已经走了」的窗口**从概率变成必然**。

台面 B（修前收场 ＋ 复现刀）逐字读数见 §三。诊断原文与 CI 上那两趟**逐字同形**：

```

end: Os { code: 32, kind: BrokenPipe, message: "Broken pipe" }
thread '…a_credentials_file_produced_by_the_write_side_routes_that_account_to_the_upstream' panicked at src/relay/server.rs:4207:13:
写侧产出的那份文件里明明有 `row-two` 这一行，这一发却没走完一条转发："" / ""

              [relay] connection ended: Connection reset by peer (os error 104)"
```

⚠ **红在「第二个账号」上**（`row-two` / `acct-b`），不是第一个 —— 与 1.1 的因果链逐字对得上。

### 1.4 失效方向（单子点名的那一条）：**成因不是「CI 机器慢」**

机器慢是**触发条件**，不是根因。根因是「桩把一条合法的客户端行为当成夹具坏了」——
它在**任何**足够慢的机器上都会红，而快机器只是恰好每次都赶在前面。
本地把那个窗口人为撑开（复现刀）⇒ **同一份代码当场 5/5 红**，这就是「它对时序敏感」的证据。

### 2.3 为什么偏偏是它俩红，而不是「撞上了但不红」

两条都**在同一条判据里发两发**（`acct-a`/`acct-b`、`row-one`/`row-two`）。
⇒ 第一发把桩炸掉，**第二发才是红的那一发**（诊断逐字红在第二个账号上，见 1.3）。
反过来说：就算某条单发的判据撞上了这一形，桩线程 panic 发生在**另一条线程**上、
且在它自己那一发已经拿到响应之后 ⇒ **那一条不会红**。
⇒ 中招要**同时**满足两条：① 下游中途走人（只有 2 条）② 之后还要再用一次 listener（这 2 条都要）。

### 2.4 所以：一处修好全族，不是只修那两条

修在**桩的收场那一处**（`spawn_fake_upstream` 的 accept 循环，全族共用的那一份夹具）⇒
对 36 条**同时**生效，不是把那两条各打一个补丁。
台面 C2（修后 ＋ 复现刀 ＋ 整族）就是这句话的读数：窗口撑开着跑整族，**0 红**。
