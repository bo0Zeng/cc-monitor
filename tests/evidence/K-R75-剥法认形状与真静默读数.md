## 五 · 量法（`§一之二` 那几个数怎么来的）

### 量法 A —— `#[cfg(test)]` 底下那一行的形态普查

在本树根跑（分母 = `git ls-files '*.rs'` 里落在三个根之下的 **198** 份）：

```python
import subprocess, re, collections
files = subprocess.check_output(['git','ls-files','*.rs'], text=True).split()
roots = ['src-tauri/src', 'remote-daemon-proto/src', 'src-tauri/crates/guard-core/src']
cov = [f for f in files if any(f.startswith(r + '/') for r in roots)]
CFG = '#[' + 'cfg('                      # 运行时拼，免得普查脚本命中自己
forms = collections.Counter()
for f in cov:
    lines = open(f, encoding='utf-8').read().split('\n')
    for i, l in enumerate(lines):
        t = l.strip()
        if not t.startswith(CFG):
            continue
        if not re.search(r'(?<![A-Za-z0-9_-])test(?![A-Za-z0-9_-])', t):
            continue
        j = i + 1
        while j < len(lines) and (lines[j].strip() == '' or lines[j].strip().startswith('//')
                                  or lines[j].strip().startswith('#[')):
            j += 1
        s = lines[j].strip() if j < len(lines) else ''
        if s.startswith('mod ') and s.endswith('{'):            forms['mod {'] += 1
        elif re.match(r'^pub(\s|\()', s) and ' mod ' in ' ' + s and s.endswith('{'):
                                                                forms['vis mod {'] += 1
        elif s.endswith('{'):                                   forms['非 mod 的花括号体'] += 1
        elif s.endswith(';'):                                   forms['声明（;）'] += 1
        else:                                                   forms['其他'] += 1
print(forms)
```

现打：`mod {` **223** · `vis mod {` **3** · `非 mod 的花括号体` **31** · `声明（;）` **23** · `其他` **26**。
列 0 / 缩进那一维另跑一遍同一段（把 `t.strip()` 换成 `l == t` 记一格）：**列 0 226 · 缩进 0**。

⚠ **这把尺子是文本级的**，它答「盘上长成什么样」，**不答**「剥法真剥了没有」——
后者的权威源是 `guard_core::production_source` 自己（`M1`–`M5` 那五刀问的就是它）。
