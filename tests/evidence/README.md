## 两条它自己也守着的边界

1. 🔴 **本目录被 `structural_scan::dead_name_corpus` 与 `launch.rs` 的散文扫描面明写排除**。
   理由：这里的量具逐字引用着死名与探针串，收进语料 = **判据被自己的量具喂饱**，真问题当场从人群里消失。

## 它们的仓根是怎么算的

`Path(__file__).resolve().parents[2]` 才是仓根（`parents[1]` 只到 `<repo>/tests`）。
新写量具照这个来，别按位置猜。
