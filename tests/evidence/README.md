## 它们的仓根是怎么算的

搬进 `tests/` 之后，`Path(__file__).resolve().parents[1]` 只到 `<repo>/tests`，
**不是仓根** —— 2026-09-18 一次性改成了 `parents[2]`（44 处，白名单驱动：
改完算出来的根必须有 `package.json`）。新写量具时照这个来，别再按位置猜。
