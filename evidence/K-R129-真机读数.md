## §2 🔴 这一趟的「干净」干净到什么程度 —— **逐条写，不许只写「在干净机器上验的」**

PM 定的路是「在那台机器上新建一个本地用户拿干净面」。**这条路我验了，它成立，但只在下面列的那几维上成立。**

### 2.1 §0d 三问的现打答案

**问一：本件要判的东西真的全在 per-user 层吗？安装器写的是 per-user 还是 per-machine？**

**不全在。安装器是 per-machine 的**，现打三处证据：
- `src-tauri/tauri.conf.json` 的 `bundle.windows.nsis.installMode` 逐字 `"perMachine"`；
- NSIS 装完，登记落在 **HKLM**：`HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\cc-monitor`，
  `InstallLocation = "C:\Program Files\cc-monitor"`；
- MSI 装完，登记同样落 **HKLM**，ProductCode `{FBA51884-C4BD-4ADE-95D1-159C48C4D5C7}`，
  `InstallLocation = C:\Program Files\cc-monitor\`。

⇒ **点名说出来：装到 `Program Files` 与 HKLM 的那一部分，新用户挡不住。**
**但本件要判的那一维（`ccm` 找不找得到）恰好不在那一部分里** —— 因为现打量到：
**这两个安装器往 `Program Files` 装完之后，`Program Files\cc-monitor` 既没进系统 PATH、也没进任何用户 PATH**（§3.2 有前后对照）。
⇒ per-machine 那一半**存在，但对本件的判据没有贡献**。这句话是**量出来的，不是推出来的**。

**问二：新用户第一次登录要不要走 OOBE / 有没有 profile 初始化的坑？**

**没走 OOBE，也没踩坑，但方式要写清**：我**没有**让这个用户走交互式桌面登录。
用 `New-LocalUser` 建号之后，从管理员会话用 `Start-Process -Credential` 跑了一次 `cmd.exe`，
**profile 目录当场被创建**（`C:\Users\kr129clean\` 下 `NTUSER.DAT` ＋ 全套 shell 文件夹齐全）。
之后给它配 `authorized_keys`，走 SSH 进去。
⚠ **代价写清楚**：这样拿到的是**非交互登录**的面，**不是** Explorer 桌面会话的面。
两者在 PATH 这一维上取自同一处（见 2.3），在**桌面/GUI** 这一维上不一样（见 §6）。

**问三：那台机器上现有的残留，新用户看不看得见？**

|---|---|---|

### 2.2 所以这一趟的「干净」= 下面这句，逐字

> **「per-user 那一层是真干净的（PATH 值 · profile · rc · `~/.cc-monitor` 四样开工时都是空的，逐条量过）；
> per-machine 那一层不干净（系统 PATH 里带着 Git 与 Node、`Program Files` 里原先装着 v3.7.0、HKLM 有旧登记）。

> 所以后者的不干净对本次结论没有贡献。」**

### 2.3 为什么「SSH 里的 PATH」能替「桌面里开一个 PowerShell」作数

Windows 上一个登录会话的 `PATH` 只有两个来源：`HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment\Path`
＋ 该用户 `HKCU\Environment\Path`。本趟**两个都直接读了注册表**（后者是把 `C:\Users\kr129clean\NTUSER.DAT`
`reg load` 挂起来读的，因为该用户没在线）：
- HKLM：`C:\WINDOWS\system32;C:\WINDOWS;C:\WINDOWS\System32\Wbem;C:\WINDOWS\System32\WindowsPowerShell\v1.0\;C:\WINDOWS\System32\OpenSSH\;C:\Program Files\Git\cmd;C:\Program Files\nodejs\`
- HKCU(`kr129clean`)：**这个值不存在**（装 NSIS 前 · 装 NSIS 后 · 装 MSI 后，三次都读了，三次都不存在）

而 SSH 会话里 `$env:PATH` 实测逐条 = 上面 HKLM 那 7 条 ＋ `C:\Users\kr129clean\AppData\Local\Microsoft\WindowsApps`
＋ 一个空条目。**两边对得上** ⇒ 桌面会话里这三条命令的解析结果不会与本趟不同。
⚠ **这条论证的边界**：它只覆盖「按 PATH 找可执行文件」。**不覆盖** PowerShell `$PROFILE` 里定义的函数
（本趟四份 profile 全不存在，所以这一格是空的）与 §0 列的那三条没查的路。
