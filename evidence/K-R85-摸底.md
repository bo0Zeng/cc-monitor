## 1 ① 今天两份各是什么形状

### 1.1 daemon `--search`（实测）

```
① 进程启动本身（CLAUDE_CONFIG_DIR 指到空目录 ⇒ projects/ 不存在，search() 立刻 Ok(()) 返回）
   10 趟：中位 2 ms · 最小 2 ms · 最大 3 ms · maxrss 11 MB

② 一次全扫（169 文件 / 691.9 MB）
   q='zzq-no-such-needle-xyz'（零命中，仍走全库）  5 趟：中位 2581 ms（2576–2752）· maxrss 101 MB
   q='cc-monitor'（13 会话命中）                   5 趟：中位 2587 ms（2581–2602）· maxrss 101 MB
   q='定时器'（14 会话命中）                        5 趟：中位 2625 ms（2579–2633）· maxrss 103 MB

③ --include-tools（把 tool 面也抽出来搜）
   q='cc-monitor'                                 3 趟：中位 3316 ms（3290–3327）· maxrss 103 MB
```

🔴 **本件最反直觉的一条读数**：**进程启动占一次查询的 0.1%**（2 ms / 2587 ms）。
⇒ `§0c` 那句「每查一次起一个进程」**在性能账上根本不是问题** ——
真正的钱全在**每次都把 691.9 MB 重新读一遍 + 重新 JSON 解析一遍**。
**「搬索引」要买的不是「省掉进程」，是「省掉重扫」。**

⚠ 还有一笔**没量到**的：远端那条路每次查询还要**新建一条 SSH 连接**
（`remote_history.rs::run_list_query` → `ssh_source::connect_and_exec_cmd`，每次 fan-out 每台一条）。
沙箱里没有远端 ⇒ **SSH 握手那一段判不了**，但它按结构一定 **≥ 2 ms 那个量级的很多倍**，
本报告**不给数**。

### 1.2 桌面侧 `search.rs`（🔴 判不了 —— 为什么）

### 1.3 能量的那半：索引到底要装多少东西（实测计数，不是估）

按 `search.rs` 的 `build_one`/`push_msg` 抽取口径（`extract_text_blocks` + `clean_user_text`
+ `extract_tool_text` + `MAIN_CAP=20000` / `TOOL_CAP=4000` 截断）在同一批语料上**逐条数出来**：

```
会话（有可索引消息的）= 163 / 169 个文件
进索引的消息条数        = 119,616
main 字符 17,893,684（UTF-8 33,748,136 B = 32.2 MB）
tool 字符 74,580,350（UTF-8 102,745,558 B = 98.0 MB）
合计     92,474,034 字符 = 130.2 MB
原文 + 小写副本两份     = 260.3 MB
```

这是**索引持有的文本量**的实测计数。`search.rs` 头注逐字「每条消息存原文 + 小写副本（2×文本）」
⇒ 内存下界 = 上面这个字节数 × 2，**再加** 每条 `MsgDoc` 的 `uuid`/`ts_ms`/`kind` 与 Rust 的
`String`/`Vec` 头 —— **那部分本轮没量，所以「索引占多少 MB」这一格仍写「判不了」**，
这里给的是**可数的那一半**。

🔴 **顺手逮到一句今天已经是假话的头注**：`search.rs:31` 逐字
「内存：每条消息存原文 + 小写副本（2×文本）。**典型用户几百会话 < ~100MB**，符合 issue 预算」。
本机 **163 个会话**（正落在「几百会话」里），光文本两份就 **260.3 MB** ——
**已经是那句话的 2.6 倍，而且没有任何东西在数它**。

⚠ 另一格：**tool 文本占索引的 81%**（98.0 / 130.2 MB），而 `include_tools` 是
**默认关闭**的开关（`search_history` 的入参，前端一个复选框）——
桌面侧为一个默认关的功能常驻付了约 4 倍内存。daemon 侧相反：`--include-tools` 没给就
**根本不抽 tool 文本**（`search_query.rs:198-205`）⇒ 这也解释了实测的 2587 ms → 3316 ms 那一跳。
