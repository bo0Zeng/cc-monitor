## 阻塞

### #1 gray(idle-tmux) Tab 是死角：关不掉、无 resume、菜单给"必失败的重启"【主线程已确认真】
- gray Tab 的 `status` 仍是 `"live"`（`markTmuxIdle` tabs.ts:1456 只翻 `tmuxIdle`）。
- ✕ 关闭：`styles.css:1161` `.tab:not(.archived) .tab-close{display:none}` 隐藏；`closeTab` tabs.ts:1673 对非 archived 直接 `return` → **关不掉**（主线程核实：closeTab 注释"仅允许关闭 archived"）。
- resume 项只在 `t?.status === "archived"`（tabs.ts:2881）→ gray **没有 Resume 项**（主线程核实）。
- idle 分支（tabs.ts:2934-2941）只给「Attach（空 tmux，无 claude）」——**不给 resume/kill**（主线程核实）。
- 账号菜单 `appendAccountMenuItems`（tabs.ts:2235）按 `status==="archived"` 分流；gray=live 走 else → 追加「用账号 X 重启…」，但 `restartTabWithAccountInner`（tabs.ts:2381）要求精确命中活 claude → 对 idle-tmux **必弹「无法换号重启」toast**（菜单主动给了点了必失败的项）。
- 后果：claude 已退但 tmux 仍在的会话，用户既关不掉、也无一键把 claude 拉回原 tmux（headline 的 "resume idle 就地复用" `runRemoteResumeIntoExistingTmux` 只被 archived 的「Resume（tmux）」调用 tabs.ts:2889，gray 上无入口）——只能 attach 进空 shell 自己敲。tmux 长存则 Tab 长期卡灰。
- 触发：远端 claude 正常退出但 tmux(登录 shell)还在 → SESSION_IDLE(lib.rs:605) → 灰 Tab，右键即复现。

## 重要

### #2 孤儿清理会把"活着的会话"误列为孤儿并请求 kill
- `findOrphanTmux`(tabs.ts:311) 判据 `isCcmTmuxName(name) && sid!=null && !tabSids.has(sid)`，**不看 command** → 任何带 `@ccm_sid` 的 `cc-*` 会话只要 sid 不在当前 tabs 里就被列孤儿，**含正跑 claude 的**（daemon 未宣告窗口 / 别的 origin / 别的实例起的）。`cleanupOrphanTmux`(tabs.ts:2577) 会放进逐个 kill 清单。确认框列了 `s.command`(tabs.ts:2593) 是缓解但文案"tab 已关、残留"对活会话是错误陈述。建议：判据排除 `isClaudeTmuxCommand`，或对 command=claude 行加强警告。

### #3 对齐/换号成功后 ~10s 内 mismatch 假阳性 → 诱导二次重启（再杀刚起来的会话）
- 对齐后 `sessionAccountsByS`（mismatch 源①）只靠 10s 轮询刷新(main.ts:257)，对齐**没立即重探**；`alignableCurrent`(tabs.ts:2417) 读旧账号 → 判 mismatch=true、⇄ 仍 eligible、⚠k 不降约 10s → 用户以为没生效再点 ⇄ → 又 kill+resume 一遍 + 再弹终端。建议：对齐成功后主动 `refreshSessionAccounts()`，或清 `restartingSids` 后短暂抑制。

### #4 右键 kill/attach 信任 8s 陈旧缓存，破坏性重启却坚持 fresh（安全标准不一致）
- 缓存命中分支(tabs.ts:2906-2931)用缓存 `m.name` 造「杀死会话」，TTL 8s；8s 内 `/branch` 漂移则按名 kill 可能**杀到漂移后的会话**。对比 restart/attach(tabs.ts:2368/2064)都注明对新鲜度敏感一律新查。建议：kill 点击时也 fresh-query 再确认。

### #5 gray Tab/grid cell 保留陈旧 activity，灯灰但文案"运行中/等待"
- `markTmuxIdle`(tabs.ts:1448-1459) **不清 `tab.activity`**（archiveTab tabs.ts:1407 会清）→ tooltip 仍拼「等待操作…」(tabs.ts:3000)、grid peek 状态对 gray 显原始 activityStatus(grid-monitor.ts:346-352)。灰灯配 waiting/busy 文案自相矛盾。建议：markTmuxIdle 时把 activity 视未知或标"(已退出)"。

### #6 弹出查看窗不订阅 onSessionActivity，红/黄活动灯永不更新
- viewer `bindEvents`(main.ts:984-1012) 缺 `onSessionActivity`（主窗有 main.ts:736）→ 弹出窗 busy/idle/waiting 灯冻结在打开那刻，只有灰/归档会变。
