### ③ 三个同名函数，只有一个该合

| 函数 | 判定 |
|---|---|
| `is_deceptive_char` | **平台无关**，且**双向漂了**（见下）⇒ 合，取并集 |
| `is_safe_config_dir` | 本机用 `looks_absolute`（认 Windows 盘符）、**必须允许 `\`** 作分隔符故改拒 `\..\`；daemon 是 Linux-only，直接把 `\` 当危险字符拒掉。**刻意的平台特化** ⇒ 不合 |
| `norm_dir` | 同上（本机多剥一层 `\`）⇒ 不合 |

硬合后两个只能二选一：要么本机失去 Windows 路径，要么 daemon 失去对 `\` 的拒绝。

### ④ 安全函数上的**双向漂移**（那条守卫看不见）

| 缺在哪 | 码位 |
|---|---|
| 本机缺 | `U+0085`（NEL，C1 换行 —— **不在 `char::is_control` 里**，daemon 侧注释特意点明过） |
| daemon 缺 | `U+2060..=U+2064` · `U+1680` · `U+2000..=U+200A` · `U+202F` · `U+205F` · `U+3000` |

一个能骗过其中一侧的名字就是能骗人的名字，与哪一侧在读无关 ⇒ **取并集**。

### 两条守卫退役 —— 因为漂移变成**不可表示**

- `contract_matches_the_daemon_implementation`（读对面源文件比四个常量）：
  两侧现在 import 同一个 `const`，想不一致得先把 import 删掉。
- `credential_filename_matches_native_identity_declaration` 的**后一半**
  （「本文件真的在用这个字面量」）：常量就是唯一定义处，结构上不可能不用。
  **前一半保留并搬进 crate** —— bash 是另一门语言，共享不了常量，那条对账仍然必要。
  搬进去而不是留在调用方：常量住哪儿，检查就该住哪儿，否则又是两份。

这是 U6b-3 那条横切约定的第三次应用：**判据能被绕过时，先问「能不能让它不可表示」。**
