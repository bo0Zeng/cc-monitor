# UB-复盘2 — `launch-core/src/cli.rs` 补自测（复盘的 P1 / U8c-3 硬前置）

- 工作区：unified-backend · 复盘产物
- 前置：UB-复盘1（P0 生产层判据，commit `75faef8`）

## 一、为什么这件是硬前置，不是「补点测试」

`cli.rs` 是**装了 ccm 的机器上真正在跑的那条渲染路径**，到今天为止**一条自测都没有**。
它唯一的judge是跨语言入库夹具（16 条）—— 而夹具的另一侧生成者是 TS 的
`launch-render-cli.ts`，**排期在 U8c-3 被删**。

那天一到：`cli-golden.json` 变成一个**没有生成者的冻结文件**，跨语言对拍退化成
「Rust 跟上次一样」的快照。于是「这个渲染器该做什么」这件事在本仓**再没有独立说法**。
⇒ 本件不做完，U8c-3 不许开。

## 三、写了 21 条判据（15 → 36），每条注明它杀谁

- **静态能力闸**：`CLI_REQUIRED_CAPS` **清单相等** + **逐项抽掉各一次**（两半都要：
  前者杀「悄悄删一项」，后者证明每项是真被执行而非只声明）。
- **七个 `Refusal` 变体的逐字理由**（生产侧唯一的降级线索），其中六句另**对着入库夹具核**
  （夹具是 TS 生成的 ⇒ 那六句不是自说自话）；`AttachNeedsTmux` 是**唯一没有夹具用例**的那条 ——
  R4 存活的原因就是它。
- **五个维度逐个**：`identity` / `account`（恒真，F05）/ `model`（条件式，§37）的
  `applies`·`cliFlags`·`requiredCaps`；两个惰性格单列（见下）。
- **三条铁律**：#76 防线先于维度循环 · §35 说不出就整条放弃 ·
  **能力闸逐维度交错**（两个方向各一条，把「先查完所有能力再渲染」这种看起来等价的实现区分开）。
- **整条命令的形状**：一条把三个吐 flag 的维度同时触发的用例，顺序即契约。
- **`argv` 的 quote 边界**：放行集逐字符 + 空 token + 落到内核那份逃逸。

### ⚠ 两处刻意的重复，理由要写清楚

判据自带 `STATIC_CAPS_EXPECTED` 与 `ARGV_BARE_CHARS` 两份清单，**刻意不复用被测常量** ——
**遍历被测常量自己是恒真的**：把 `"cwd"` 从 `CLI_REQUIRED_CAPS` 删掉，任何「遍历该常量逐项
抽掉」的循环也就不再测 `"cwd"`，变异照样全绿。**R5 存活的形状正是这个。**

（造变异时这两份重复还当场绊了我一次：R5 的锚点同时命中了判据里那份清单，
`assert count==1` 直接把脚本拦下 —— 那个 assert 值。）

## 五、R1 / R3 仍存活 —— 这是死代码发现，不是判据缺口

`env-reset` 与 `nested-env-reset` 两格的 `cli_flags` **恒返回空**，`caps` 也是空，
所以**改它们的 `applies` 改不了任何输出**；`env-reset` 更进一步：它只在
`send_into: true` 时触发，而那种形态在维度循环**之前**就被 #76 防线拒掉了 ⇒ **不可达**。

⇒ 给 R1/R3 造行为判据是不可能的。硬造出来的只会是仪式性判据（正是复盘 P3 要删的那种）。
本件的处置是**钉住真正要紧的那两件事**：

1. `the_two_inert_dimensions_contribute_no_flags_for_any_shape` —— 惰性本身。
   哪天有人给它们加了真 flag，这条红（而夹具未必抓得到：`env-reset` 那格根本到不了）。
2. `env_reset_can_never_be_reached_in_the_cli_renderer` —— 不可达性本身（**这条杀掉 R2**）。
   哪天 #76 防线被挪走，它红，提示「env-reset 变活了，去补夹具」。

并把「不可达 + 惰性」写进这两格的代码注释 —— 此前它们看着像正常的维度实现，
读的人不会知道改了没用。

## 六、顺带还清一条 P2

`cli.rs` 的「顺序即契约」注释写着「这里用数组顺序 + **下面那条测试**钉住」——
而**当时下面一条测试都没有**（复盘点名的「引用了不存在的测试」）。现在改成指名
`a_fully_loaded_invocation_emits_every_part_in_registry_order`，并把订正留痕：
**指向不存在的判据比没有注释更坏 —— 它让人以为那一层有人守着。**
