## 这个工作区要做什么

**把「后端」集成成一个。** 今天「起 / 停 / 接一个会话」有多条各写各的路：
cc-monitor 经 ssh 跑 `shared/ccm`（1300 行 bash）· 用户在终端里直接敲 `ccm` ·
本机走 PowerShell + `wt.exe`（完全不经 IR）· monitor 自己开 ssh 跑 `tmux kill-session` ·
cc-bus 的 spawn 又一套。而 daemon 至今是**纯观察者**，一条执行路都不经它。
