# G3b-2 — 分叉之后起会话的编排（含追问）

G3a 答「参数该是什么」，G3b-1 让后端能带账号，本步做**编排**：推断 → 该问就问一次 → 起。

## §1 依赖注入：要守的是**判断**，不是副作用

`ask` / `startLocal` / `startRemote` 全部注入。三件都是副作用（弹窗、拉终端、走 ssh），
而本模块真正要守的是三条判断：

1. **知道就别问** —— 否则每分叉一次弹一次窗，功能没人用。
2. **不知道就必须问，且绝不自己填一个。**
3. **tmux 名必须换** —— 同名会让 `ccm` 把新会话 attach 进原窗口，
   变成「一个窗口两条对话轮流出现」，正好毁掉这个功能的意义。

注入之后这些判断可直接测，不必驱动真弹窗（同 `readiness.ts` 注入 `statusOf`）。

## §2 ★ 变异 S4 报绿，揪出**最重要那条不变量**的覆盖缺口

S4 = 「未知账号时拿调用方塞进来的 `liveConfigDir` 顶替」。**第一轮它是绿的。**

原因：我的 `DEAD` 夹具**没带 `liveConfigDir`** ⇒「顶替」与「落 null」结果相同，
测试根本区分不了。而这恰恰是「**绝不拿当前账号顶替**」的实际形状 ——
调用方（比如从 chip 拿当前账号）很自然会把它填上。

`fork-launch.ts` 的 P1 守的是**推断层**；编排层这条**当时没人守**。已补
`★★ 已退出 + 调用方塞了 liveConfigDir + 弹窗没答账号 → 仍然是 null`，重跑 S4 见红。

**这就是变异测试的价值**：不是确认已有测试有效，是找出**没写的那条**。

## §4 顺手撞出并绕开一个守卫缺口（登记 E75）

G3b-1 里写的 `const SHELL_META: &[char] = &['\'', '"', …]` 让 **C04a 命令名守卫当场打红**，
报出一个不存在的命令 `build_resume_ps_command`「声明了却没注册」。

根因：`test-support/strip-comments.ts` 的状态机**不认 Rust 字符字面量** ——
`'"'` 里的双引号被当成字符串起点，**此后整个文件的注释都不再被剥**；
而 `history.rs` 后面一段 doc 注释里恰好有 `` `#[tauri::command]` `` 字样，就被当成了真属性。

与该文件头注记的那次是**同一类、方向相反**：那次是 `"…/*\/bin"` 里的 `/*` 被当成块注释开始，
**吞掉 521 行真代码**（假阴性、危险）；这次是假阳性（fail-closed、会叫）。

**本轮绕法**：`&[char]` 改写成 `&str`（字符串里的转义引号状态机认得），并在那行上方写明
为什么不能写成字符数组。**改措辞不改守卫。** 真修法（给状态机加字符字面量识别）登记 E75 ——
它被 6+ 个守卫共用，改它要连它自己的测试一起补例。
