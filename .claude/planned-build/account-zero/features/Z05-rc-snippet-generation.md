## 2. 关键设计决定：**片段从远端抓，不在 TS 里重写一份**

片段的形态（`export CLAUDE_CONFIG_DIR=<默认号>` + 每账号一个 `<名>cc()` + Z01 加的
`0cc()` 逃生口）是 **`cc-acct-iso` 的知识**。两条路：

| 路 | 代价 |
|---|---|
| **在 TS 里照抄一份生成逻辑** | 多一个**跨语言双写点** —— 正是本工作区反复在治的病（`TMUX_LS_FMT` / `NATIVE_IDENTITY` / `--base`）。而且它会随账号数、默认号、launcher 名变化，抄错的表现是**用户贴了个坏 rc** |
| **抓远端 `shellinit` 的输出** ✓ | **单一来源留在 bash**，一处都不用同步 |

选后者。已有现成的 `exec_collect(&cfg, cmd)`（SSH exec 抓 stdout，`check_remote_acct_iso` 就用它）
⇒ 新增一个只读命令 `remote_acct_iso_shellinit`。

**只读性已逐行核过**：`cmd_shellinit` 全是 `printf`，不写任何文件。它更不会去动
用户的 `~/.bashrc` —— 贴不贴由用户决定，这是明令的红线，`paste-block.ts` 的模块头也写死了
「本文件没有、也不得有任何写入路径」。

`2>/dev/null` 丢掉 warn（例如「manifest 里没有默认账号」）：那些混进 stdout 会让片段贴了就坏。

## 3. fail-closed：**半截片段绝不放行**

`validate_shellinit_output()` 抽成纯函数（SSH 那半测不了），要求 **BEGIN 与 END 围栏都在**：

> 只查 BEGIN 的话，一次被截断的输出（SSH 中途断、超时）会带着半截片段过关，
> 而**半截片段贴进 rc 会让用户的登录 shell 直接报错**（未闭合的函数体）。

两种失败给**不同的可执行诊断**：
- 有 BEGIN 没 END ⇒ 「**不完整**…输出可能被截断了。**别贴**…请重试」
- 连 BEGIN 都没有 ⇒ 「没能产出…常见原因：cc-acct-iso **未安装**（先在维护里部署）、或还没 `init`」

前端 `invalidReason` **再校验一遍**：能显示 ≠ 能贴。组件在拒绝时**绝不碰剪贴板**
（把半成品写进剪贴板，用户粘出去就是坏配置）。

## 4. 跨语言双写点守卫

`SHELLINIT_FENCE_BEGIN` / `_END` 两个常量必须与 vendored `cc-acct-iso` 里
`cmd_shellinit` 真正 `printf` 的那两行**逐字一致**。漂了的表现是
**功能整体失灵、但错误文案听起来像用户的错**（「远端没能产出 rc 片段」）。

⇒ `acct_iso_shellinit_fence_matches_vendored_script`：`include_str!` 读 vendored 副本 + 锚定两行
+ 反向自检（源真读进来了）。做法同 `tmux.rs` 那条与 `accounts_query.rs` 的 Z06 守卫。
**`cp -a` 保 mtime ⇒ 本地 re-vendor 后要 `touch` 本文件**（Z06 实测过的坑）。

## 5. ★ 撞出一个守卫的结构性盲区：`accounts-section.ts` 现在**两族都属于**

T03 的 `paste-block-guard.vitest.ts` 把全仓 `writeText` 分两族白名单：
族 A（待贴配置文本，必须走组件）· 族 B（复制完就完事，契约不同）。
`accounts-section.ts` 原先是**纯族 B**（复制命令 / 复制路径 / 复制诊断文本）。

Z05 给它加了一个**真·待贴块** ⇒ 它同时有两种语义，而 **A/B 二分覆盖不了这种文件**：

- 塞进族 A ⇒ 被「族 A 里不得再出现裸 `writeText`」打红（那三处是正当的族 B 用途）
- 留在族 B ⇒ 被「族 B 不许出现待贴语义」打红（守卫自己的诊断就写着「真要做待贴块，
  就得走组件、从族 B 挪进族 A」）

**处置：新增族 AB，判据从「有没有 `writeText`」换成「`writeText` 处数恰好等于已登记数」。**

理由：族 A 那条规则真正要防的是「有人手搓一个复制按钮绕开组件」。对混合文件而言，
能表达这个性质的是**计数上下界**（`accounts-section.ts` 实测 3 处：`:300` 复制命令 /
`:703` 复制路径 / `:799` 复制诊断文本）—— 多出一处就说明又手搓了一个。
同时仍要求它 `import buildPasteBlock`（族 A 侧的约束保留）。

**这不是把守卫放松，是把它的判据换成能覆盖新形状的那个。**
